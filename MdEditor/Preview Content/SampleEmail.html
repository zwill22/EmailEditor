Content

This is the content of the email, specified by the EmailProps argument. To change this text, pass a string to the content element. Additional content is specified by other elements in the. I will break these down here:

EmailProps

Here is a breakdown of the current properties supported by EmailProps, the placeholder values are in italic:

  • name: A person's full name for the header (Name For A Person)

  • info: A list of information about the person, such as job titles: (Info, Scientist, Strategist)

  • title: The email title (Title)

  • content: The emails contents in Markdown format. For a summary of what may be included, see below.

  • headerLinks: A list of links for inclusion in the email's header. The format for these is explained below.

  • footerLinks: A list of links for inclusion in the email's footer, same format as headerLinks.

  • previewText: Some brief text summarising the email, this appears in the email list in most clients and is often the first few lines of the messsage (Preview text showing summary of the email)

  • copyright: A copyright notice (Person B Nameson)

Markdown emails

The emails support markdown formatting, to demonstate the available formatting, I will provide some examples:

Titles

These can be written using:

  • # Title

  • ## Subtitle

  • ### Title 3

  • etc.

Formatting

Different text formatting is available, including:

  1. Plain: Plain

  2. Bold: **Bold**

  3. Italic: _Italic_

Lists

Lists can be written in two ways:

Numbered: 

1. One

2. Two

Unnumbered: 

- First point

- Second point
Code

It is often necessary to include code listings. These can be either inline, for example constexpr x = 42;, using `constexpr x = 42;`, or as a block: 

int main() {
    return 0;
}

Written using:

```cpp

int main() {

return 0;

}

```

Links and images

Links can be included using:

  • click me: [click me](example.com)

  • click me: [click me][example-link]

Where example-link is specified separately using: 

[example-link]: https://example.com

Images can be specified in a similar way. For example:

  • : ![Github Logo](https://raw.githubusercontent.com/zwill22/Signature/refs/heads/main/images/github.png)

  • : ![Github Logo][github-logo]

Quotes

Quotes can be included in blocks using:

To lose is to win, and he who wins shall lose!

> To lose is to win and he who wins shall lose!

Separators

Contents may also be separated using a horizontal line separator, using

___:

Link Props

Links are specified to the template using a LinkProps object, the arguments for which are summarised here:

  • href: The URL for the link

  • text: The text displayed with the link (Optional)

  • img: A link to an image to be displayed beside the link text

  • alt: Alternative text to describe the image

Summary

Markdown is handy for emails! Edit props.content to remove this text.
